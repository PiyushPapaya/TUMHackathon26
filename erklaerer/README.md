# erklaerer/

Eine Seite zum Anfassen, die das ganze Projekt erklärt. Wer braucht das: alle, die verstehen wollen, was wir bauen.

**Öffnen:** Doppelklick auf `index.html` (läuft im Browser, ohne Internet, ohne Installation).

Sie führt einen echten Kundenkommentar (`G60-0019`) durch alle sieben Schritte. Du kannst die Gewichte der Priorisierung verschieben, Entscheidungen treffen und einen Audit Trail fälschen.
Echt sind Kommentare und Zahlen aus den BMW-Daten. Die Beispielwerte beim Priorisieren sind ausgedacht und so markiert.

Etwas ändern? Die Datei ist normales HTML. Sag Claude: „Ändere in `erklaerer/index.html` den Schritt X, weil …“.
