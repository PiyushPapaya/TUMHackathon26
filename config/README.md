# config/

Ein Szenario ist eine Kombination aus Modell und Markt. Wer braucht das: Builder, und alle, die ein neues Modell zeigen wollen.

| Datei | Szenario |
|---|---|
| `scenarios/G60-US.json` | 5er (G60), USA. **Demo-Fall.** |
| `scenarios/G70-US.json` | 7er (G70), USA |
| `scenarios/F70-EU.json` | 1er (F70), Europa |

Neues Modell oder neuer Markt: eine JSON-Datei kopieren, Felder anpassen (Dateien, Länder, Wettbewerber), Pipeline mit `--scenario <id>` starten.
