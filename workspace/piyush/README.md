# Arbeitsbereich Piyush

Hier darf Piyush alles ablegen, ohne Konflikte mit anderen: Notizen, Prompts, Recherche, Entwürfe, Prototypen, Screenshots.

- `notizen.md`: laufende Notizen und gute Prompts
- `experimente/`: Prototypen, Skripte, Screenshots

Regeln:
- Nur Piyush schreibt hier. Andere lesen höchstens.
- Ein PR, der nur diesen Ordner ändert, ist schnell gemerged.
- Keine Secrets (auch nicht „nur kurz“). Das Repo ist öffentlich.
- Dieser Ordner ist per `export-ignore` aus dem Abgabe-Snapshot ausgeschlossen und verbraucht kein Review-Budget.
